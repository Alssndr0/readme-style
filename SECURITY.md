# Security policy

## Reporting a vulnerability

Please report security issues privately through
[GitHub's private vulnerability reporting](https://github.com/Alssndr0/readme-style/security/advisories/new),
not in a public issue. You will get an answer within a week.

## Scope

readme-style reads the README and the project files next to it (manifests, workflows, license,
`.git/config`, logo names) and writes only the README it was asked to style, atomically. It makes no
network requests and runs no other programs. Reports about content it writes into a README, such as
HTML or links that could mislead a reader, are in scope too.
