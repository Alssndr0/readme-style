# Examples

Three fictional projects, each with its original `README.md` and one styled file per theme.
They are also the snapshot tests: `tests/test_examples.py` fails when a change to
readme-style alters any of them, and `scripts/build_examples.py` regenerates them.

The projects do not exist, so dynamic badges (versions, CI status) render as "not found".
